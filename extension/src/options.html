Where the button appears

QuickRun can start almost any repository: if there is no configuration it reads the files and works out a plan itself. That plan is a considered guess, and you always see the exact commands before anything runs - but you may prefer the button only where the repository says how it wants to be started.

The last two ask QuickRun on your machine whether those files exist, once per repository. That check needs QuickRun to be running; when it is not, the button appears anyway rather than disappearing without explanation.
